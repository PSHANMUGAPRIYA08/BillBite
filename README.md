# 🍽 Restaurant Billing Web App

A simple and user-friendly restaurant billing system built using HTML, CSS, and JavaScript.

---

## 🚀 Features

- 🔐 Login / Signup system
- 👨‍💼 Admin panel
- 🍛 Food menu with images
- 🔍 Search food items
- 🛒 Add to cart & billing
- 💳 UPI QR Code Payment
- 🧾 PDF Bill Download
- 📊 User count tracking

---

## 🛠 Tech Used

- HTML
- CSS
- JavaScript
- LocalStorage
